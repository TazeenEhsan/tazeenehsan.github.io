I'm Tazeen Ehsan, a **WordPress & WooCommerce Plugin Developer** with around 4.5 years of professional experience building plugin-based solutions for WordPress and WooCommerce stores.

My core focus is plugin architecture, WooCommerce customization, and dynamic, React-powered Gutenberg blocks. Day to day I work across PHP, JavaScript (ES6+), the WordPress Block API, and the WordPress/WooCommerce REST APIs to ship features that fit into existing store and site architectures.

## What I do

- Design and build WordPress and WooCommerce plugins, from product customization features to store-specific business logic
- Build dynamic Gutenberg blocks and custom editor experiences using React and the WordPress Block API
- Extend WooCommerce through hooks, filters, and the REST API to support custom business requirements
- Optimize plugin and page performance, and debug issues across the WordPress/WooCommerce stack
- Work as part of a development team, using Git-based workflows to ship, review, and maintain plugin code

## Background

Most of my professional experience has been on commercial WordPress plugins — leading development on [WowAddons](/projects/wowaddons/), a WooCommerce product-customization plugin, and contributing as a supporting developer to [PostX](/projects/postx/) and [WowStore](/projects/wowstore/), alongside custom WooCommerce plugin work built to specific business requirements.
